# ahlun@localhost

## >> An interactive, web-based terminal simulating a linux command-line interface.

This project serves as a personal site built to reflect my identity as a developer and my aspirations. It showcase my background, social connections, and a "dream" linux setup directly in the browser...

## >> Available Commands

| Command | Description |
| :--- | :--- |
| `help` | Lists all available commands |
| `motd` | Displays the Message of the day banner and last update date |
| `whoami` | Outputs my background, interests, and developer journey |
| `music` | Displays my favorite music tracks (currently coming soon) |
| `neofetch` | Shows my dream system specifications and daily OS setup |
| `network` | Lists my professional and social media links |
| `clear` | Clears the terminal output |
